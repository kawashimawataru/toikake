# 問いかけ（Web 版）

中村研のフィールドワーク研究で使う記録アプリ。フィールドワーク中に学生が見たこと・
感じたこと・考えたことを、**その場で外に出して記録する**（思考の外在化）ためのもの。

写真を撮ると、その場で質問が出る。声で答えると、続けて「もう1枚こう撮ってみて」と
追加の記録を促す。写真だけでは残らないこと（大きさの実感・音・匂い・動き・写真の外に
あったもの）を取りに行かせるのが狙い。

## 使い方

URL を開いて参加者を選び、「はじめる」を押すだけ。インストールは要らない。
「共有 → ホーム画面に追加」しておくと次から1タップで開ける。
**自動ロックは「なし」にする**（画面が消えるとマイクが止まる：WebKit bug 226620）。

記録は端末の中（IndexedDB）にだけ貯まる。サーバーには送らない。
回収は「記録を終える → この記録を書き出す（zip）」で行う。

zip の中身は iOS 版と同じ形：

```
session.json   解析用のデータ本体
photos/        撮影画像
audio/         回答音声（文字起こしは事後に Mac 側で行う）
```

## 中身

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面 |
| `app.js` | 撮影 → 問い → もう1ターン の進行 |
| `engine.js` | 問いの設計（段階・A/B・もう1ターンの型・しきい値） |
| `vad.js` | 発話検出。iOS 版 `VoiceActivityDetector.swift` の移植 |
| `store.js` | 端末内保存と zip 書き出し |
| `missions.js` | お題。**`state.json` から自動生成**（`tools/gen_missions_web.py`） |
| `sw.js` | オフライン用 |
| `verify.mjs` | 通し検証。仕様を変えたら必ず通す |

お題を直すときは `state.json` を直して `python3 tools/gen_missions_web.py` を流す。
`missions.js` を直接編集しない。

## 検証

```bash
node verify.mjs     # 撮影 → A/B の問い → もう1ターン → zip 書き出し まで通しで確認
```

マイクは偽のデバイス、写真は `富士宮FW/IMG_4132.JPG` を差し込んで動かす。
playwright がグローバルに入っていること。
